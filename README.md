# 🏦 Bank Loan Risk Analytics

## End-to-End Portfolio Analysis, Risk Modeling & Executive Dashboard

An end-to-end data analytics project that transforms **38,576 consumer loan records** into actionable insights about portfolio performance, borrower default risk, loan economics, and executive-level monitoring.

The project uses **SQL, Python, Advanced Excel, and Power BI**, with each tool serving a different purpose:

- **SQL (SQLite):** Portfolio-level performance analysis
- **Python:** Borrower-level risk analysis and default prediction
- **Excel:** Formula-driven operational tools and calculations
- **Power BI:** Interactive executive monitoring and reporting

The objective is to identify high-risk lending segments **before loans are funded**, helping support better underwriting and risk-based decision-making.

# 📌 Project Overview

This project analyzes a consumer lending portfolio containing **38,576 loan applications** and builds a complete analytics workflow from raw data to business decision-making.

The analysis follows this pipeline:

```text
Raw Loan Data
      ↓
Data Cleaning & Validation
      ↓
SQL Portfolio Analysis
      ↓
Python Risk Analytics & Predictive Modeling
      ↓
Advanced Excel Operational Tools
      ↓
Power BI Executive Dashboard
      ↓
Business Reporting & Recommendations
